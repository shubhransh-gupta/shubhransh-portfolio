# Shubhransh Gupta — Interactive iOS Engineering Portfolio

Interactive, storybook game-art portfolio and resume for **Shubhransh Gupta**, Senior iOS Developer (Primarily) · SDE-2 at Coupang.

## ⛵ Features
- **Procedural Line-Art Wave Engine**: Real-time multi-harmonic sine waves animated via vanilla canvas & SVGs.
- **Dynamic Physics & Drift**: Galleon tracks swell height and slope angle; low-resolution canvas casts soft animated palm shadows.
- **Single-Take Camera Move**: Smooth transition from open ocean to pirate island with captain and treasure chest.
- **Comprehensive Resume Modal**: Interactive parchment logbook with work experience (Coupang, Navi, MakeMyTrip, Nuclei), open source contributions (Apple, Google, AppLovin, Fastlane), skills matrix, and downloadable resume.
- **Zero External JS/CSS Dependencies**: Built entirely with plain HTML5, CSS3, and modern vanilla JavaScript.
